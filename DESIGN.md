# ITSBAD Labs Design System v1.0

Use the CSS tokens and components in `/assets/css/`.

## Required rules
- Mobile-first from 360px upward.
- WCAG 2.2 AA-oriented implementation.
- 44px minimum preferred interactive targets.
- Product color is not semantic status color.
- Use semantic HTML and visible focus.
- No unsupported claims, fake metrics, fake social proof, or fake freshness.
- Distinguish source publication time, event/record time, and retrieval/check time.
- Avoid generic AI motifs, excessive gradients, glassmorphism, floating blobs, gratuitous cards, and decorative dashboards.
- Use the ITSBAD pink signature sparingly.
- Use product accents only on product-specific surfaces.

## Voice
Clear, specific, calm, human, evidence-aware, never hype-first. Prefer precise verbs to generic CTAs.
