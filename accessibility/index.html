Accessibility

Access is part of the product.

ITSBAD Labs aims to build digital experiences that are usable across devices, input methods, and assistive technologies.

Our baseline

We design toward WCAG 2.2 AA, use semantic HTML, visible keyboard focus, responsive layouts, readable contrast, and reduced-motion support.

Continuous improvement

Accessibility is tested and refined as products evolve. If something prevents you from using an ITSBAD Labs experience, we want to know about it.

Known v1 limitation

A dedicated accessibility feedback contact will be added when the business contact channel is finalized.
